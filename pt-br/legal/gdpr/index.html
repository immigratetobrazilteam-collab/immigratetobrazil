Declaração de alinhamento com o GDPR

Esta página oferece transparência no estilo GDPR onde essa estrutura é relevante para o usuário ou para a situação.

Deve ser lido como um aviso suplementar para utilizadores internacionais que pretendam informações mais claras sobre direitos, tratamento transfronteiriço e o quadro jurídico aplicado aos dados pessoais.

Seção 02

Identificação do controlador de dados

A prática responsável deve ser claramente identificada.

Para efeitos deste site e fluxo de trabalho do serviço, o ponto de contacto relevante é Monique Fernandes / Imigre para o Brasil, utilizando os dados de contacto publicados nesta plataforma.

Seção 03

Base jurídica para processamento

A base para o processamento depende da razão pela qual os dados estão sendo usados.

Isto pode incluir etapas pré-contratuais solicitadas pelo usuário, necessidade contratual, obrigações legais, interesses legítimos, consentimento quando apropriado, ou o estabelecimento, exercício ou defesa de reivindicações legais.

Seção 04

Categorias de dados tratados (esclarecimento contextual)

As categorias devem corresponder ao contexto real do serviço.

Eles podem incluir informações de contato, detalhes de identidade, fatos de imigração, cronologia, comunicações, registros carregados, informações relacionadas a pagamentos e informações de uso técnico limitado relacionadas ao site.

Seção 05

Direitos explícitos dos clientes da UE

Esta página deve facilitar a compreensão dos direitos fundamentais.

Dependendo da situação, uma pessoa pode ter direitos como acesso, retificação, apagamento em algumas circunstâncias, restrição, objeção, portabilidade quando aplicável, e o direito de retirar o consentimento quando o consentimento for a base jurídica utilizada.

Seção 06

Reconhecimento de transferência transfronteiriça

A prática internacional exige um reconhecimento claro do tratamento transfronteiriço.

Como Monique atende clientes no Brasil e no exterior, os dados pessoais podem ser armazenados, comunicados ou revisados entre jurisdições, quando necessário para o serviço ou infraestrutura de suporte.

Seção 07

Princípios de retenção e minimização de dados

A retenção deve ser limitada ao que é necessário para o trabalho e para o contexto jurídico.

Monique pretende reter apenas o que for razoavelmente necessário para o tratamento de consultas, prestação de serviços, registros de pagamento e conformidade ou defesa de direitos.

Seção 08

Relacionamento com representação legal e contratos reguladores

Este aviso acompanha a estrutura de privacidade e quaisquer termos formais de serviço.

Se um assunto passar para uma fase de serviço definida, o tratamento dos registros deverá ser lido em conjunto com a Política de Privacidade e os termos escritos ou o âmbito que se aplicam a essa fase.

Seção 09

Processo de reclamação

Os usuários devem saber que podem existir rotas de autoridade supervisora em sua própria jurisdição.

Quando o GDPR for aplicável, um usuário também poderá apresentar uma reclamação a uma autoridade supervisora relevante, além de entrar em contato primeiro com a prática para esclarecimentos.

Seção 10

Ponto de contato

Dúvidas sobre privacidade devem ir para o canal de contato publicado para que possam ser analisadas adequadamente.

Solicitações, correções e dúvidas sobre privacidade podem ser enviadas para moniquefadv@gmail.com, com detalhes suficientes para identificar o problema e os registros envolvidos.
