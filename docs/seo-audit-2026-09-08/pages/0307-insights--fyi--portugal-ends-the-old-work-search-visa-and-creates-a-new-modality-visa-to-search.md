Portugal ends the old work search visa and creates a new modality: visa to search for qualified work Portuguese consulates have already stopped issuing the old "work search visa", as it no longer exists in the previous format. The change is the result of Law No. 61/2025, which amended the Foreigners Law and completely reformulated the typology of this visa. In its place, the visa for searching for qualified work appears, aimed at "highly qualified" professionals; the exact definition of these qualifications will still be detailed by ordinance. For now, it is not possible to apply for the new visa: the regulations to define who qualifies are still being prepared.
