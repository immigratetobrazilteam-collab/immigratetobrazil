# Page-by-page rewrite index

Use `master-ledger.csv` as the index for **all 1,720 URLs**. Each row names a page dossier and, where applicable, its exact HTML metadata and JSON-LD files. Dossiers contain the current and proposed title, description, H1, targeting, intent, outline, opening proposal or source-recovery hold, content changes, internal links, media recommendations, canonical, robots, schema and priority.

There are **351 ordinary editorial drafts**, **386 country-evidence drafts**, **22 legal-content retargeting drafts**, **6 consolidation-review entries**, **944 article source-review holds**, **10 noindex utilities** and **1 verification utility**. None is recorded as deployed.

**This is not a completed publication-ready rewrite of 1,720 pages.** The original run generated full-site coverage, but many dossiers contain family-level planning instructions, and archive placeholders cannot be repaired with metadata. Every retained draft still needs its visible content checked against its promise; all explicit source dependencies are listed in `unfinished-editorial-ledger.csv`.

For articles, “AFTER … HOLD” records a retained/provisional value for comparison, not approved new copy. Withheld alternatives are intentionally not fabricated. For countries, the common planning introduction is conditional and cannot stand in for the required origin-specific evidence table. Do not bulk publish those drafts unchanged.

The sitemap proposal now targets the observed final URL `/sitemap`. Current URLs remain recorded in the BEFORE inventory. A utility verification page must preserve its token, with no metadata/schema replacement.

Complete a page by satisfying the dossier's factual requirements, selecting a unique intent, writing the missing answer, checking locale quality, updating the metadata/schema/body together and marking the ledger's review and deployment state accurately. Do not mark a page complete solely because its metadata file exists.
