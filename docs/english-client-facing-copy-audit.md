# English Client-Facing Copy Audit

This audit was made from the split English inventory in `docs/client-facing-text-inventory-en/`.
It focuses only on English client-facing text.

## Main Findings

1. Shared site copy is generally professional, but several repeated labels read mechanically or inconsistently.
Examples include `Whyus`, `Faqs`, `Get The Newsletter PDF`, and form copy that says `this page` too often.

2. The site relies on repeated generated image text such as `Hero image for the ... page showing ...` and `Cinematic background of ...`.
That wording is functional, but it reads like internal website metadata instead of polished client-facing accessibility text.

3. Universal consultation forms are present across the English site, but the heading `Request a consultation about this page` makes the action feel page-centric instead of client-centric.
The surrounding copy can more clearly invite a concise matter summary while preserving legal caution.

4. Several hub and sidebar sentences use internal planning language such as `route family`, `page that matches`, or duplicated wording like `Attorney Monique and Monique Fernandes`.
The stronger direction is to keep the same legal meaning while making the visitor feel guided by attorney-led judgment.

5. The site repeats legally careful disclaimers and consultation notes, which is appropriate.
The copy should keep that caution while removing unnecessary repetition, internal jargon, and rough generated phrasing.

## Improvement Direction

- Keep the tone calm, premium, legally careful, and practical.
- Preserve all services, routes, legal cautions, forms, analytics, and structure.
- Improve shared English partial copy first because it appears across most pages.
- Improve repeated generated HTML strings mechanically where the meaning is stable.
- Avoid adding unsupported guarantees, deadlines, prices, outcomes, or new legal rules.
- Regenerate the split English inventory after the source copy changes so the files match the real site.
