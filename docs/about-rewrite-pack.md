# About Page Rewrite Pack

This file is the non-destructive rewrite guide for the English `About` family.

Use it page by page. Keep the existing HTML structure in each `body.html`, but replace the prompt-like text with the copy direction below.

## Voice Rules

- Write to the client, not about the site.
- Keep the tone professional, warm, direct, trustworthy, and calm.
- Focus on how Immigrate to Brazil helps, guides, clarifies, coordinates, and reduces risk.
- Avoid sounding like a law textbook, a firm brochure, or generic SEO copy.
- Do not mention Monique, Irish, or any OAB number outside `/about/lawyer/`.
- Do not promise outcomes, approvals, or timelines.
