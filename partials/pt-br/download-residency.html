Baixe o Guia de cuidados para autorização de residência brasileira

Uma autorização de residência brasileira é um passo importante, mas não é o fim das suas responsabilidades legais.

O Guia de cuidados para autorização de residência ajuda os residentes atuais a se manterem organizados após a aprovação e a se prepararem para futuras etapas legais.

Cuidados de residência Planejamento de renovação Futuras etapas legais

Este guia é útil para:

  • Cidadãos estrangeiros com residência brasileira
  • Pessoas se preparando para a renovação
  • Famílias que vivem no Brasil
  • Clientes planejando residência permanente
  • Moradores se preparando para a cidadania
  • Qualquer pessoa que queira manter os registros de imigração organizados
